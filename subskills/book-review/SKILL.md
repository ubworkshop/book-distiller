# 高穿透读后感与书评生成子技能 (Sub-skill: book-review v2.7)

本子技能作为 `book-distiller` 的专属创作表达层，将拆解出的章节内容及 `extract-insights` 萃取的“4+2 黄金原料”一键转化为适合各大社交平台的**高穿透力爆款读后感与书评**，并**同步生成完整的血统溯源与联系图谱**。

---

## 一、核心创作哲学：反课文复述，重生活投射

> **「读者并不是想看你写这本书说了什么，而是想通过这本书，看清他自己最近为什么过得这么累。」**

### 3 大铁律：
1. **禁止“中学语文课代表式复述”**：坚决不写“作者先在第一章论述了A，接着在第二章论述了B”。
2. **表面聊书，实解内耗**：将书中的理论作为“手术刀”，精准剖开当代人在工作、情感、拖延、金钱、人际中的具体困境。
3. **沉静克制，杜绝爹味**：严格遵循用户设定人设：
   - 语气：像深夜和一位信赖的老朋友在窗前交谈。
   - 视角：平视、同理、真诚，不居高临下，不兜售焦虑，不用廉价叹号。

---

## 二、双重输出标准：正文排版 + 完整血统溯源与联系图谱

每一次生成读后感，必须同时交付以下两大部分：

### Part 1: 平台专属排版正文
根据指定的目标平台（小红书 / Threads / 公众号），选用最佳心流排版（详见 `templates/review-templates.md`）：
- **模具 A：小红书深度读后图文**（痛点直击 + 双行反差标题 + 3个顿悟点 + 标签）
- **模具 B：Threads / X 串帖读后感**（4帖心流结构，每帖 ≤ 500 字符）
- **模具 C：公众号 / 博客深度随笔**（生活散文引入 + 概念解构 + 现实困境剖析 + 治愈收尾）

### Part 2: 完整血统溯源与联系图谱 (Provenance & Lineage Blueprint)
清晰展现文章的设计来源，让创作过程 100% 透明可查：
1. **📊 创作设计联系图谱 (Mermaid Diagram)**：
   - 直观可视化：`【原著章节/概念】 ➔ 【insights/ 原料库转化】 ➔ 【社交媒体表达心流】`
2. **📋 核心要素血统溯源表**：
   - 追踪每个核心文案（标题Hook、痛点、认知反转、行动清单、金句）对应原书的哪一章哪一节、对应 `insights/` 的哪个文件、以及背后的**创作者心理学意图**（如：降低防御、引起共鸣、提供安全感、促成收藏）。
3. **🧠 关联知识双链 (Obsidian Wikilinks)**：
   - 标注文章激活的原书概念模型双链（如 `[[反思回路]]`、`[[第一性原理]]`）。

## 三、原料流动与智能挂载机制

```mermaid
flowchart LR
    A[拆分章节 Markdown] --> B[extract-insights]
    B --> C[insights/ 四大总库]
    C --> D[book-review 子技能]
    D --> E[各平台读后感正文]
    D --> F[🧬 完整血统溯源与联系图谱]
```

1. **优先抽取**：若目标书籍目录下存在 `insights/` 文件夹，自动从以下总库精准调度素材：
   - `00_全书爆款选题与反直觉库.md` ➔ 提取标题、开篇反直觉切入点 (Hook)
   - `00_读者现实痛点与对号入座索引.md` ➔ 提取第一幕引起读者共鸣的现实病症
   - `00_全书高穿透金句大全.md` ➔ 提取中段作为顿悟支撑的灵魂点睛金句
   - `00_全书核心概念与思维模型图谱.md` ➔ 提取行动解法中的底层逻辑框架
2. **溯源绑定**：将上述调取的每一项原料精确记录至血统溯源表中。

## 四、触发与使用方式

### 方式 1：自然语言对话驱动（推荐）

在任何时候，直接对 AI 下达指令即可：

```text
# 示例 1：指定平台与主题，附带血统溯源
"帮我用小红书风格写一篇《xxx》的读后感，探讨'摆脱讨好型人格'，并附上完整的血统溯源与联系图谱"

# 示例 2：基于特定章节写 Threads 串帖与图谱
"根据第 03 章写一组 Threads 4 帖心流串帖，画出文章的设计联系图谱"
```

### 方式 2：使用脚本生成完整脚手架

在终端中使用内置脚本：

```bash
# 生成带有血统溯源图谱的草稿文件
python3 scripts/generate_review.py "/path/to/book_output" --platform all --topic "自我成长与内耗"
```

生成的文件将自动保存在书籍目录下的 `reviews/` 文件夹中，内置 Mermaid 联系图谱与溯源表格骨架。

## 五、质量自检清单 (Checklist)

在输出任何一篇读后感前，必须通过以下自检：
- [ ] **是否戒断了爹味？**（语气温和平视，杜绝指点江山）。
- [ ] **是否包含联系图谱 (Mermaid)？**（清晰展示原著理论向社交文案的演化路径）。
- [ ] **血统溯源表是否完整？**（每一处核心观点都能找到原书和原料卡出处）。
- [ ] **是否在前3秒抓住读者？**（开篇第一句话直接道破读者的隐秘痛苦）。
